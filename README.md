# DSN Internship Assessment

This repository contains solutions to a Python assessment covering basic programming concepts.

## Contents

### 1. Rectangle Class
A class that calculates the area and perimeter of a rectangle using width and height.

### 2. Word Count Script
Reads a text file and returns the total number of words in the file.

### 3. List Processing
Filters out numbers divisible by 3 from a list and squares the remaining numbers using list comprehension, `map`, and `lambda`.

### 4. Division Function
A function that performs division between two numbers and handles division-by-zero errors.
